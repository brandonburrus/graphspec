# Goals

- Author software specifications as a navigable knowledge graph.
- Validate a spec before generating or changing code.
- Traverse the spec to decide what to build and in what order.

# Pains

- Free-form specs are ambiguous and hard to machine-check.
- Relationships between requirements, architecture, and tests are implicit.
